## Flagged items

**P01** — the chart is substantively right: correct variables (constant-PPP GDP per
capita is a defensible reading of "GDP per capita"), 2019, all countries, log-x with
dollar labels, muted shape-21 scatter defaults intact, `save_fig("full")`, rotated
y-title, source line present. Three compliance issues:

1. **Invented `gl_setup(mode = "standalone")`.** `theme_gl()` only branches on
   `mode == "report"`, so the unknown string silently fell through to slide-style
   behavior (title/subtitle/caption rendered) at report-mode 9pt sizing — a hybrid
   state no spec describes. Recommended fix at the top of the ladder:
   `match.arg(mode, c("report", "slide"))` in `gl_setup()`/`theme_gl()` so a wrong
   mode errors instead of half-working. (Arguably reasonable *instinct* by the session
   — the prompt asked for a standalone PNG, for which slide mode is right — but the
   API let it guess a mode that doesn't exist.)
2. **Zero baseline at gridline weight.** Savings go negative, so y = 0 is part of the
   frame of reference; the chart shows only the ordinary gridline. Should be
   `gl_zero_line()` (rule 12). The skill states this; the session missed it —
   worth watching whether this recurs across the battery (P05/P09/P16 stress it
   directly) before deciding if it needs a stronger home than skill text.
3. **Title doesn't end in a period** — since the session opted into in-chart titles,
   the statement-of-finding period rule applies (rule 13). Minor; title is also a
   topic label, not a finding, which is its own (softer) issue.
