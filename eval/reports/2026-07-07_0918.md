## New findings

1. **Single-series scatter ambiguity (P01).** The first battery's session left the
   all-countries cloud in the muted default; this one painted it `highlight` blue
   with dark strokes at 0.8 alpha — a legitimate reading of rule 3's "a
   single-series chart is a focus series with no backdrop: opt into color."
   Both are defensible under the current text, so the skill is ambiguous where a
   scatter has no focus. Needs one clarifying line: is an unfocused all-units
   scatter "the data" (muted) or "one series" (blue)? Nil's samples lean muted —
   propose: *scatter clouds without a highlighted subject stay muted; blue enters
   only when something is singled out.*
2. **Treemap rules meet a case the spec doesn't cover (P15).** The chart is the
   most ambitious of both batteries — correct `hs_sectors` palette, WCAG
   luminance-aware white/dark in-tile labels, value + share lines. But Nil §8
   says tiles abut with **no stroke**, and this product-within-sector treemap
   uses white product separators + thick sector borders — arguably *necessary*
   at ~1,800 tiles, and visually it reads as sector blocks (close to the Atlas
   house style). Second: `min.size = 5` lets small tile labels shrink below the
   12px floor. Decide upstream: does §8's no-stroke rule apply only to flat
   sector-level treemaps, with paper subgroup borders sanctioned for two-level
   treemaps? And in-tile labels should drop (treemapify does this) rather than
   shrink below the floor.
3. **P15 left intermediates in `/tmp`** (Atlas classification CSV, fig dir) —
   the reproducibility pattern from the first battery, now with artifacts
   outside the run folder. Reinforces the pending "self-contained scripts" line.

## Addendum — fixes applied and rulings (same day)

All three pending items above were applied after Taimur's review:

- **`match.arg(mode, c("report","slide"))`** in both `gl_setup()` and
  `theme_gl()` — invented modes now error with a clear message (verified).
  SKILL.md rule 9 gains the destination rule: standalone PNG → slide mode;
  report mode only when a document supplies the caption block. Checklist
  updated.
- **`highlight_sz` rule** added under rule 12 + checklist: no muted layer →
  no `highlight_sz`; lone/coequal series stay at the standard 2px default.
- **Zero-scan nudge** added under rule 12: before saving, check each value
  axis — 0 inside the plotted range (sparse negatives count) needs
  `gl_zero_line()`.

Two rulings from the review, both propagated grammar → skill:

- **P16's muted "Unspecified" bar: rejected.** When color encodes sign, every
  bar follows the sign encoding — a lone grey bar among blue gains and red
  losses reads as a third category and breaks the flow. This report's earlier
  praise of the muting is overruled; grammar §3.6 and SKILL rule 4 now state
  the sign-encoding rule.
- **P15's treemap borders: sanctioned.** Two-level treemaps (products within
  sectors) take thin paper separators + thicker paper sector borders; the
  no-stroke rule now applies only to flat single-level treemaps. In-tile
  labels drop rather than shrink below the 12px floor. Grammar §3.4 and
  SKILL rule 16 updated.
